== Migrating to the eventuate-common split

link:eventuate-common-split/README.adoc[eventuate-common-split/README.adoc] is the migration guide for the repositories split from eventuate-common.
It lists their groups, coordinates, version properties and packages, and says how to run the recipe `io.eventuate.common.split.MigrateToEventuateCommonSplit`, which migrates a consumer.
